# BeatBear 🐻

키보드/마우스 입력에 맞춰 **곰이 연주하는** 전체화면 데스크톱 오버레이입니다.
투명·클릭통과 창이라 평소엔 다른 앱을 그대로 쓰고, **곰 위젯 위에서만** 상호작용해요.
친구와 방에 모여 함께 두드리고, 무기·미사일로 서로 맞히고, **배틀 모드**로 대결할 수 있습니다.

## 실행

```bash
npm install
npm start                 # 오버레이 앱
npm run server            # (멀티할 때만) 릴레이 서버 — ws://<호스트IP>:8787
```

- 접속하지 않아도 **혼자 모드**로 동작합니다.
- 하단 바의 **햄버거(≡) 메뉴**에서 꾸미기·소환·컬렉션·미니게임(배틀)·멀티·설정을 조작합니다.
- 캐릭터를 드래그해 위치를 옮길 수 있어요.
- 단축키: `Ctrl+Shift+B` 채팅 · `Ctrl+Shift+M` 미사일(커서 유도) · `F2` 하단바 숨김

## 멀티플레이

**서버가 곧 방입니다**(방 코드 없음). 한 명이 서버를 켜고 주소를 공유하면, 그 주소로 접속한 사람끼리 함께 놉니다. 다른 그룹은 서버를 하나 더 띄우면 됩니다. 한 서버 최대 12명.

1. **서버 켜기** — Node 있으면 `npm run server`, 없으면 릴리스의 **`beatbear-server.exe`** 를 클릭(항상 최신 버전으로 실행).
2. **접속** — 앱 메뉴 → 멀티플레이 → 서버 주소 입력:
   - **같은 Wi-Fi/랜**: `ws://<서버PC_IP>:8787` (서버를 켜면 콘솔에 접속 주소가 표시됩니다. 방화벽 8787 인바운드 허용이 한 번 필요할 수 있어요.)
   - **다른 네트워크**: 터널(`npx localtunnel --port 8787`)·클라우드·포트포워딩으로 `wss://...` 접속

> ⚠️ 클라와 서버 **버전이 같아야** 접속됩니다(버전 게이트). exe 런처는 항상 최신 릴리스로 뜨므로 자동으로 일치합니다.

## 프라이버시

네트워크로는 입력 **펄스 신호만**(`key`/`mouse`) 전송합니다 — **어떤 키를 눌렀는지는 절대 수집·전송하지 않습니다**.
